Toys / a shader instrument

Bermuda

Bermuda draws patterns on the GPU, live: hexes, stars, pinwheels, rings. Each look is a stack of levels - a lattice, a shape, a twist, a colour - and any knob can ride a slow wave or a MIDI control.

Open Bermudasource on GitHub

Playing it

  • Tab hide the panels
  • E edit
  • Space pause
  • 1 - 0 jump to a look
  • [ ] step through presets
  • M MIDI learn

What it needs

Runs in a desktop browser with WebGL2. A MIDI controller is a bonus, not a must.

Ten looks come with it. Every knob can be tied to a modulator - a slow cosine called breathe is my favourite - or learned to a MIDI control.
